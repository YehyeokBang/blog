# 개발자용 문서 배포 흐름 이미지 디자인

## 목적

`ai-html-document-sharing` 게시물에서 개발자가 HTML 문서를 Git으로 올린 뒤 S3에 자동 배포하고, 문서 목록이 README에 정리되는 흐름을 한눈에 설명한다.

## 구성

- 가로형 3단계 흐름: `HTML 문서` → `Git push` → `S3 자동 배포`
- `README 문서 목록 자동 정리`는 자동 배포 단계 아래의 보조 결과로 표현한다.
- 각 단계는 단순한 선형 아이콘과 짧은 한국어 문구로 구성한다.
- 화살표와 민트 포인트 컬러로 진행 방향을 명확히 한다.

## 스타일

- 크기: 1600×900px
- 형식: WebP
- 배경: 흰색
- 색상: 블로그 디자인 토큰의 `ink`, `body`, `hairline`, `primary` 계열
- 장식은 최소화하고 과한 그림자, 그라데이션, 입체 효과는 사용하지 않는다.
- 본문 폭으로 축소해도 단계명과 흐름을 쉽게 읽을 수 있어야 한다.

## 검증

- 출력 크기가 1600×900px인지 확인한다.
- WebP 파일이 정상적으로 열리는지 확인한다.
- 문구가 정확하고 잘리지 않았는지 시각적으로 확인한다.
- 축소된 블로그 본문에서도 세 단계와 README 보조 흐름이 구분되는지 확인한다.
