# SEED 참고 기록

- 출처: [SEED](https://seed-design.io/)
- 저장소: [daangn/seed-design](https://github.com/daangn/seed-design)
- 마지막 확인일: 2026-08-12

## 참고 목적

SEED의 결과물을 복제하지 않고, 개인 기술 블로그에 맞는 역할 기반 디자인 판단과 접근성·문구 원칙을 검토하는 외부 참고 자료로 사용한다.

## 차용하는 원칙

- 역할 기반 토큰
- 제한된 간격 스케일
- 컴포넌트 역할 구분
- 접근성
- 명확한 문구
- 로딩 시간에 따른 피드백

## 프로젝트에 맞게 변형하는 원칙

- 민트 브랜드 색을 유지한다.
- 차분한 개인 기술 블로그 말투를 사용한다.
- 기존 Tailwind 토큰을 유지한다.

## 채택하지 않는 항목

- SEED 패키지 설치
- 당근 색상·말투·브랜드 자산
- 앱 전용 navigation·sheet 구조
- 아직 필요하지 않은 컴포넌트

## 다시 검토하는 조건

새로운 UI 패턴이 필요하거나 기존 선택이 반복해서 문제를 일으킬 때, 실제 사용자 흐름과 현재 구현을 먼저 확인한 뒤 관련 SEED 공식 문서를 다시 검토한다.
